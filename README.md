# Projekt z użyciem Express + EJS + SQL - Dynamiczna strona z formularzem zapisujacym dane w bazie danych.
# Program urachamiany po przez pisanie komendy node index.js w terminalu.
# Aby użyć narzędzia deweloperskiego który wypełni bazę danymi testowymi należy uruchomić program używając komendy POPULATE_DB=1 node index.js (zadziała tylko jeśli w bazie nie ma żadnych rekordów
# Strona główna jest dynamiczna, umozliwia dodawanie wiadomości przez formularz, wyświetla je, pozwala na edycje jak i usunięcie.
# Uzyte npm: better-sqlite3@12.5.0, ejs@3.1.10, express@5.1.0 oraz morgan@1.10.1
